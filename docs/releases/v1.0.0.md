## DeepSeek 双语字幕 v1.0.0

首个开源版本：为 Edge 当前标签页显示原文与简体中文字幕，识别和翻译均使用你自己的 DeepSeek API Key。

### 下载与安装

下载下方 **deepseek-edge-subtitles-v1.0.0.zip**，解压后进入 `edge://extensions`，开启“开发人员模式”，选择“加载解压缩的扩展”，加载包含 `manifest.json` 的文件夹。在视频页点击扩展图标，填写 Key，然后开启字幕。

### 功能

- 标签页音频 → DeepSeek ASR → DeepSeek 中文翻译。
- 双语字幕浮层，支持拖动、字号调整及网页全屏。
- 最长 3 / 4 / 6 秒分段、停顿断句、有限积压队列。
- 默认会话内保存 Key，可选本机保存；无项目后端，无统计追踪。
- 中英文 README、隐私说明和 MIT 许可证。

### 验证与限制

7 项自动测试通过，Edge 浏览器模拟流程验证通过。初始验证使用人工音频和模拟接口，**尚未使用真实 DeepSeek Key 验证识别/翻译质量、费用或延迟**。ASR 不支持流式识别，因此字幕是分段近实时更新。画中画和部分受保护页面/媒体不支持。调用费用由你的 DeepSeek 账户承担。

## DeepSeek Bilingual Subtitles v1.0.0

First open-source release: original-language and Simplified Chinese captions for the current Edge tab, using your own DeepSeek API key for both speech recognition and translation.

### Download and install

Download **deepseek-edge-subtitles-v1.0.0.zip** below, extract it, open `edge://extensions`, enable Developer mode, and choose Load unpacked. Select the folder containing `manifest.json`. Open a video tab, enter your key in the extension popup, and start captions.

### Included

- Tab audio capture → DeepSeek ASR → DeepSeek Chinese translation.
- Draggable bilingual overlay, font controls, and webpage fullscreen support.
- 3/4/6-second maximum segments, pause splitting, and bounded buffering.
- Session-only key storage by default, optional local storage; no project backend or analytics.
- English/Chinese READMEs, privacy documentation, and an MIT license.

### Validation and limitations

Seven automated tests pass, along with simulated browser checks in Edge. Initial validation uses synthetic audio and mocked responses: **real DeepSeek transcription/translation quality, billing, and latency have not been validated with a live key**. Captions are chunked and near-real-time, not word-by-word streaming. Picture-in-picture and some protected pages/media are unsupported. API usage is billed to your DeepSeek account.

See the repository README for setup, permissions, troubleshooting, and development. `SHA256SUMS.txt` contains the SHA-256 checksum of the installable ZIP. Use the named ZIP asset for installation; GitHub's automatically generated source archives contain development files too.

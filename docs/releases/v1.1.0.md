## 修复句中断开与上下文翻译

v1.0.0 每 3/4/6 秒就截断音频，只翻译当前片段，即使带有前文，也无法用后半句修正前面的语义。v1.1.0 改为持续累积当前话语并修订字幕。

- **刷新不切句**：3/4/6 秒现在表示刷新间隔，同一句从开头持续累积，约 0.7 秒停顿后定稿。
- **随下文修订**：新词到达后重新翻译完整当前话语，参考最多四段前文原文与译文；原文和中文一起更新。
- **超长话语衔接**：18 秒强制换窗，保留 1.2 秒重叠音频，并尽可能去除重复文字。
- **防止旧片段积压**：同一句仅保留最新待处理版本，跳过话语时重置上下文。

### 更新

下载 `deepseek-edge-subtitles-v1.1.0.zip`，更新扩展文件，在 `edge://extensions` 点击“重新加载”，刷新视频页后重新开启字幕。保留原有设置，原“分段长度”现在作为“刷新间隔”使用。

### 代价与验证

同一句音频会重复上传，**ASR 用量和费用会增加**；6 秒刷新通常比 3 秒刷新请求更少。停顿不一定是语义上的句末，超长连续讲话仍可能存在衔接误差。

12 项自动测试及 Edge 浏览器模拟检查通过，覆盖音频累积、同条字幕修订、停顿定稿、重叠去重、双语上下文等。没有使用真实 DeepSeek Key 验证翻译质量，不能保证消除全部误译。

## Fix mid-sentence cuts and improve translation context

v1.0.0 split audio at every 3/4/6-second interval and translated each piece separately. v1.1.0 recognizes growing utterances and revises the caption when later words clarify the meaning.

- The setting now controls **refresh frequency**, not hard cuts. A roughly 700 ms pause finalizes the utterance.
- Re-translate the entire current utterance using up to four preceding original/translated pairs; update both subtitle lines together.
- Roll over very long utterances at 18 seconds with 1.2 seconds of shared audio and best-effort text deduplication.
- Coalesce pending revisions and reset context across skipped utterances.

### Update

Download `deepseek-edge-subtitles-v1.1.0.zip`, replace the extension files, click Reload at `edge://extensions`, refresh the video page, and restart captions. Existing settings are retained; the old segment-length value becomes the refresh interval.

### Tradeoff and validation

Repeated recognition uploads some audio more than once, **increasing ASR usage and cost**. A 6-second refresh interval usually sends fewer requests than 3 seconds. Acoustic pauses do not guarantee semantic sentence boundaries, and long-window transitions can still be imperfect.

Twelve automated tests and mocked Edge browser checks pass, covering cumulative audio, in-place caption revisions, pause finalization, overlap handling, and bilingual context. Live DeepSeek translation quality has not been validated with a real key.

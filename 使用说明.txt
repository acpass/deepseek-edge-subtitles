DeepSeek 双语字幕 · Edge 扩展 v1.0.0

作用
捕获你开启字幕的那个浏览器标签页的声音，用 DeepSeek 识别原文，再用 DeepSeek 翻译成简体中文。
原文在上，中文在下。原文识别完成先显示，译文随后更新。

安装（不需要安装开发工具）
1. 解压 DeepSeek-Edge-双语字幕.zip，保留解压后的文件夹。
   如果使用已经提供的 deepseek-edge-subtitles 文件夹，可以跳过解压。
2. 在 Edge 地址栏输入 edge://extensions 并打开。
3. 开启“开发人员模式”，点击“加载解压缩的扩展”。
4. 选择包含 manifest.json 的 deepseek-edge-subtitles 文件夹。
5. 在 Edge 工具栏的扩展菜单中找到“DeepSeek 双语字幕”，可将它固定到工具栏。

使用
1. 打开需要观看的视频、直播或其他有声音的普通网页。
2. 点击扩展图标，填入你自己的 DeepSeek API Key。
3. 默认翻译模型为 deepseek-flash，使用非思考模式。也可以填写你账户可用的 DeepSeek 聊天模型名称。
4. 点击“开启当前页字幕”，然后播放视频。可以关闭扩展设置面板，字幕会继续运行。
5. 默认最长约 4 秒一段；检测到停顿时可能提前提交。可以选择 3 秒或 6 秒。
6. 拖动字幕顶部状态栏可移动字幕。A− / A+ 调整字号。“停止 ×”停止捕获及后续请求。
7. 也可以从扩展面板点“停止字幕”。刷新、跳转或关闭目标标签页会停止字幕；需要时请重新开启。
8. 一次处理一个标签页；在另一个标签页开启时，会先停止原来的捕获。

接口
语音识别：https://api.deepseek.com/v1/tools/asr
中文翻译：https://api.deepseek.com/v1/chat/completions
两项使用同一个 DeepSeek API Key。扩展无需本地服务器，无第三方转发服务。
语音识别上传格式为单声道 48kHz、16-bit PCM WAV。
翻译只携带当前字幕和最多两段先前原文作为上下文，关闭思考模式。

数据与费用
只捕获选定标签页的音频，不调用麦克风，不采集页面正文或视频画面。
音频片段上传给 DeepSeek 做识别，原文文字上传给 DeepSeek 做翻译，按你的 DeepSeek 账户计费。
不在磁盘保存录音或字幕历史。识别和翻译使用短暂内存队列。
默认 Key 保存在扩展会话存储中，浏览器会话结束后清除。
勾选“在这台电脑记住 Key”后，Key 保存在本机扩展存储中，不同步，但不作额外加密。
扩展不会把 Key 注入网页；只有扩展自身向 api.deepseek.com 请求时携带 Key。
停止会取消尚未完成的本地请求；已到达 DeepSeek 的请求仍可能被计费。
关闭 Edge 最后一个窗口不一定会退出后台进程。若要立即清除 Key，可删除扩展或清除该扩展数据。

体验与限制
DeepSeek ASR 当前不支持流式识别，因此这里是“分段近实时字幕”，不是逐字即时字幕。
实际延迟 = 等待音频分段 + 网络/识别耗时 + 翻译耗时，不能保证固定秒数。
连续说话时可能在分段边界切断词句；6 秒分段通常能提供更多上下文，但等待更久。
当网络或接口速度跟不上播放时，最多保留两段待处理音频，并丢弃较旧片段以减少积压；界面会提示。
静音片段会跳过，但音乐、噪声和多人同时讲话仍可能影响识别。
支持原始语言自动识别，输出简体中文；中文原声时两行内容可能接近。
字幕随结果到达显示，没有与播放器时间轴精确对齐。快进或拖动进度后可停止并重开，清空旧音频。
Edge 内部页面、新标签页、扩展商店等受保护页面无法注入字幕。部分受保护媒体或特殊播放器可能不支持。
网页全屏已用模拟页面验证；画中画是另一个窗口，当前版本不向画中画窗口绘制字幕。
要求 Edge 124 或更高版本，建议使用最新版。

常见问题
没有字幕：确认视频正在有声播放、已经点“开启当前页字幕”，查看字幕顶部或扩展面板的状态提示。
401：检查 Key。
402：检查 DeepSeek 余额。
403：确认账户可使用 ASR 和聊天接口。
404：确认翻译模型名称在你的账户中可用。
超时或频繁跳段：检查网络，尝试 6 秒分段，或暂停后重新开启。
设置变更：保存后重新开启字幕才会应用。
连续三段失败或遇到鉴权/余额等错误时，扩展会自动停止，避免不断重试。
